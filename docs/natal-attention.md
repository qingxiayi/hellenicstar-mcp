# 本命重点的分组阅读视图

2026-10-23。输出 `attention_layers`，当前版本 `natal-attention-v3`。发布状态见[本轮验收](validation/natal-jones-release-2026-10-23.md)。它消费既有图谱与证据审计，不重新计算星历、尊贵或相位。

v1验收发现的对冲端点入口及包含关系折叠问题已在v2修正，见[修复验证](validation/natal-attention-v2.md)。原[验收记录](validation/natal-attention-acceptance.md)保留用于对照；这两项修复不等于复原报告作者的全部取舍。

## 阅读对象与规则

1. `primary_structures` 保留所有定位终端及未被更大构型包含的构型。终端显示成员、汇入比例和主要入口；构型显示角色、包含及共享关系。没有把最广覆盖的终端自动认定为心理核心，也没有强制唯一终端。
2. `cross_focus` 列出至少两个明确角色组共同指向的行星。角色组包括身份、定位承接、合轴、相位网络；v3排除琼斯格局角色，后者单独在 `jones_view` 展示。这是项目的阅读规则，不是从报告恢复的原始公式，也不意味着统计独立。
3. `specific_focus` 保留只有一个角色组的行星。例如单独合轴仍值得明确展示，不因缺少第二条依据被删除。
4. `associated_context` 保留其余行星；全部状态与相关相位仍在十星画像里。未进入交叉重点不等于没有作用。

同一行星兼具终端入口与命主星定位星角色时，两者归入同一个定位承接组；多个身份归入身份组；多个构型角色归入同一个相位网络组。构型角色包括顶点、调节角色和对冲端点，两端使用相同规则；普通成员不因此自动升级。

v2保留被大构型包含的角色与紧密相位，`aspect_network_evidence` 列出原依据及其最大代表构型，`network_geometry_ids` 给出去重后的几何事实集合。同一对冲被多个构型使用仍只有一个相位网络组；多个条目不是多个独立投票。所有紧密相位均可补充已有角色，不因被构型包含而归零；仅仅参与紧密相位仍不会独自升级为单星重点。两宫制、互容与闭环同义表达不制造新角色。

日月身份仍有固定审阅入口，但它们不是每张盘必然的心理中心。状态、逆行、失势、落陷和游离不参与本层角色选择；这些是完整画像里的另一个问题。

## 如何读取

行星分组互斥且完整覆盖十星，结构组与行星列表可以重叠。`planet_audit` 说明每颗星的角色组、证据ID、终端成员身份、主要入口身份、构型关联以及旧接口是否入选。列表内部按稳定标识排列，没有总分或强制数量上限。交叉重点为空或很宽都如实输出。

消费者应同时展示主要结构、交叉重点和单入口重点。仅展示 `cross_focus` 会漏掉只担任主要定位入口或单独合轴的对象。多个终端、多个最大构型也不保证会压缩为一个主线。

v4本命选择与v3注意力层移除了琼斯入口，因此 `priority_planets`、`focus_selection` 及部分注意力标签会变化；完整画像与关系事实保持不变。详见[迁移说明](natal-jones-parallel-view.md)。v2的新构型角色筛选在 `attention_layers` 中完成；`legacy_selected` 可与新分组不同，不应拿旧名单再次裁剪新分组。新客户端需要主动读取 `attention_layers`；旧客户端不会自动获得修复。本轮未更新网页或部署服务。

## 边界

这是对已有筛选依据的重新组织，改进的是结构地位和入选原因的可辨认性；不是已证明更接近报告作者的最终判断。身份、几何与守护角色仍可能相关，不能把角色组数量称为独立证明数量。规则没有通过任何私人案例的指定名次来调参。

测试与合成样本记录见[本地验证](validation/natal-attention-v1.md)。
