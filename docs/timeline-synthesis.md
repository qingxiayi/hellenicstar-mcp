# 综合时间线

`calculate_timeline_synthesis` / `timeline-synthesis-4`，查询输入仍是出生资料、`target_year` 和 `span_years`（1–3）。日期按出生地点时区划分日历年；出生当年从出生时刻起算。整体查询受黄道释放引擎约束，终点须在出生后 100 年内。

当前 v4 为本地开发与验收版本，尚未部署或同步公开分发；线上已发布版本仍为 v3。此处说明的是当前源码，发布证据另见 [release status](release-status.md)。

## 返回内容

| 字段 | 用途 |
| --- | --- |
| `events` | 法达、黄道释放周期；次限日月换座；次限十行星对本命十行星/四轴的合刑冲；行运木土天海冥对本命十行星的合、六分、刑、三分、冲及合四轴 |
| `aspect_windows` | 上述行运和次限相位处于项目容许度内的连续区间，包括查询期间从未精确命中的区间 |
| `progressed_context` | 查询起点的次限日月星座、八阶段月相及查询期间的换相时刻 |
| `resonances` | 原有同目标、至少两种技术、精确点起向后 30 天的分组规则，保持独立；未做新视图的轴点归并 |
| `natal_context` | 十行星与四轴位置、两种宫制的落宫及直接宫主关系、十行星之间的本命直接相位 |
| `reading_windows` / `exact_contacts` | 轴点等价接触归并后的持续区间与精确接触，保留原始数组引用 |
| `concurrent_segments` | 真正同期存在的配置集合；每段内所有成员同时处于各自容许度内 |
| `window_overlaps` | 同期触及相同目标，或触及有直接本命相位的两个目标；逐对给出实际交集和依据 |
| `reading_layers` / `reading_counts` | 发展背景与周期、持续配置、精确接触的阅读顺序，以及四类新数组的完整数量 |

四轴行运仍仅合相，没有新增刑轴。次限相位仍只含合刑冲；太阳/月亮之外的换座、换宫、移动的次限四轴和太阳弧不在此次范围。

## 相位区间

- `start_utc` / `end_utc`：与查询范围相交后的区间，起点包含、终点不包含。
- `orb_entry_utc` / `orb_exit_utc`：在扩展搜索范围找到的真实容许度边界，可以在查询年份之外。找不到时为 `null`，不能把 `start_utc` 或 `end_utc` 当成真实进入/退出时刻。
- `entry_status` / `exit_status`：`found`、`search_limit`，进入边界还可能为 `birth_limit`。进入时间不向出生前推断。
- `continues_before_query` / `continues_after_query`：区间是否延续到查询范围之外。
- `angle`：规范化相位角。`directed_angle`：固定本命黄经减移动黄经的方向角；六分、刑、三分的两个方向分开记录。
- `orb_limit`：该条实际使用的容许度。
- `exact_event_indices`：落在该区间内且属于同一配置的 `events` 索引，可能为空。不同查询的索引不可互换。

重复接触继续作为独立的精确事件返回，行运事件 `source` 保留 `direction`、`series_id`、`contact_index`、`contact_total`。这些序列沿用行运工具的 365 日分组规则，不能解释为整个心理过程的长度；退出容许度后再次进入会返回两个区间，即使精确点属于同一接触序列。

## 计算口径

复用现有行运/次限容许度，不采用书中新的一套阈值。木星沿用行运模块的 fast 组，土天海冥用 slow 组。完整数值与分组公开在 `settings.window_policy`，此处的组名是既有计算分类。

实际行运向查询两端扩展 400 天；次限向两端扩展 3 个回归年，并限制在出生后至次限引擎支持的 120 岁内。搜索未覆盖完整区间时显式返回未知边界，不保证任意长期配置都能找到起止。容许度只是所选规则下的几何范围，不是情绪、关系或现实事件的实际起止。

区间扫描使用行运 1 天、次限非月亮 7 个民用日、次限月亮 1 个民用日网格；加入速度变号求得的留驻点，再求两侧容许度边界。时间精度声明为分钟。精确事件仍由现有求根器计算；区间可以出现没有精确事件的留驻擦边接触。没有新增留驻事件或心理阶段标签。

次限月相由次限月亮减次限太阳计算，每 45 度一个阶段；不是次限月亮对本命月亮的周期。`phase_at_start` 是查询起点状态，`phase_transitions` 为空只表示窗口内没换相。次限日月换座事件仍在 `events` 内。

## 如何连接已有数据

这是项目定义的 `timeline-reading-1` 阅读规则，不是 Forrest 的原版算法，也不自动确定共同心理主题。

- **真正同期**：全部区间采用 `[start_utc, end_utc)`。仅边界相接不算重叠。`concurrent_segments` 用区间端点划段，列出每段同时在容许度内的所有配置；不能把 A 与 B 重叠、B 与 C 重叠推成 A/B/C 同期。
- **关联理由**：`window_overlaps` 只在实际交集存在时记录两个配置。`same_natal_target` 表示同一本命点或同一轴线；`direct_natal_aspect` 表示两颗目标星在本命有直接相位，可由 `natal_aspect_index` 追溯。不同技法不是必要条件，`different_techniques` 单独标记。单纯同期而无这两种关系的配置仍完整保留在 `concurrent_segments` 中。
- **直接本命背景**：复用现有本命计算的十行星五大相位，统一含边界 6° 容许度；不重建被原始计算器遗漏的相位。`points` 保留普拉西度与整宫制落宫；`ruled_houses` 分传统宫主与现代替代宫主（天/海/冥分别替代水瓶/双鱼/天蝎的传统宫主）。不沿定位星链递归，不把关联星算成新增行运命中。四轴没有直接本命相位资料时明确标记 `not_in_this_view`。
- **轴点等价去重**：同一移动星、同一技法、同一几何位置下，合下降与冲上升属于一次接触。新视图按规范方向角归并轴点，保留两个来源；同一轴线的不同位置、不同移动星、不同技法，以及退出后再次进入的区间不会合并。精确轴点记录只在相差不超过 60 秒且目标为另一端点时归并，以覆盖次限求根的分钟精度；顺逆行的不同次接触继续保留。
- **区间边界**：`reading_windows` 的边界是归并后且经查询裁切的区间，不能解释为真实进入或退出。展开 `window_indices` 对应的原始 `aspect_windows`，才能读取真实边界、未知边界、容许度和精确命中。

所有 `*_indices`、`index` 和 JSON Pointer `*_ref(s)` 都只对应该次完整响应。使用 `include` 或摘要时，不得重新编号截断的数组；需要解引用应保持同样输入读取完整相关顶层字段。`reading_counts` 保留完整数量，摘要中数组可能截断。

## 三层阅读与核对

1. `reading_layers.development_background`：查询起点的次限日月/月相、期间换座与换相；法达、黄道释放周期分项保留。起点状态不冒充任意所选日期的状态。
2. `reading_layers.stage_configurations`：全部已有持续区间，按开始时间排序；通过重叠、本命直接关联查看同期背景。这里不评分，也不自动筛选最重要配置。
3. `reading_layers.precise_contacts`：每次精确接触及当时持续中的配置。这些是时刻标记，不是已证实的现实事件触发；本版没有新增快速行运。

先计算，再核对，最后结合当事人现实解读。重叠、直接结构关联和心理解释属于不同层次；系统不选唯一主线，不以条目数量评分，不推断确定事件。

v4 增加阅读字段，保持 v3 的 `events`、`aspect_windows`、`progressed_context`、`resonances` 计算不变。旧 `resonances` 的计数不能与新视图混合累加。输出契约核对几何、宫主、引用与派生视图成员；重新派生视图只证明规则一致性，不是独立的星历或心理判断验证。`verify_calculation_claims` 支持按本次 `calculation_reference` 重算并核对新字段。

## 性能口径

v3 相比更早版本增加行运对象与扩展区间搜索，计算耗时会增加。v3 发布服务器的固定样例首次测得一年约 2.3 秒、三年约 3.6 秒；这不是每次请求的服务承诺。回归测试为完整计算设置 10 秒上限，几何边界、重复接触、跨年及字段一致性检查独立保留。
