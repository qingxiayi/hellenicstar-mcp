# 综合时间线

`calculate_timeline_synthesis` / `timeline-synthesis-3`，查询输入仍是出生资料、`target_year` 和 `span_years`（1–3）。日期按出生地点时区划分日历年；出生当年从出生时刻起算。

## 返回内容

| 字段 | 用途 |
| --- | --- |
| `events` | 法达、黄道释放周期；次限日月换座；次限十行星对本命十行星/四轴的合刑冲；行运木土天海冥对本命十行星的合、六分、刑、三分、冲及合四轴 |
| `aspect_windows` | 上述行运和次限相位处于项目容许度内的连续区间，包括查询期间从未精确命中的区间 |
| `progressed_context` | 查询起点的次限日月星座、八阶段月相及查询期间的换相时刻 |
| `resonances` | 原有同目标、至少两种技术、精确点起向后 30 天的分组规则。没有新增本命结构关联或心理主题推断 |

四轴行运仍仅合相，没有新增刑轴。次限相位仍只含合刑冲；太阳/月亮之外的换座、换宫、移动的次限四轴和太阳弧不在此次范围。

## 相位区间

- `start_utc` / `end_utc`：与查询范围相交后的区间，起点包含、终点不包含。
- `orb_entry_utc` / `orb_exit_utc`：在扩展搜索范围找到的真实容许度边界，可以在查询年份之外。找不到时为 `null`，不能把 `start_utc` 或 `end_utc` 当成真实进入/退出时刻。
- `entry_status` / `exit_status`：`found`、`search_limit`，进入边界还可能为 `birth_limit`。进入时间不向出生前推断。
- `continues_before_query` / `continues_after_query`：区间是否延续到查询范围之外。
- `angle`：规范化相位角。`directed_angle`：固定本命黄经减移动黄经的方向角；六分、刑、三分的两个方向分开记录。
- `orb_limit`：该条实际使用的容许度。
- `exact_event_indices`：落在该区间内且属于同一配置的 `events` 索引，可能为空。不同查询的索引不可互换。

重复接触继续作为独立的精确事件返回，行运事件 `source` 保留 `direction`、`series_id`、`contact_index`、`contact_total`。这些序列沿用行运工具的 365 日分组规则，不能解释为整个心理过程的长度；退出容许度后再次进入会返回两个区间，即使精确点属于同一接触序列。

## 计算口径

复用现有行运/次限容许度，不采用书中新的一套阈值。木星沿用行运模块的 fast 组，土天海冥用 slow 组。完整数值与分组公开在 `settings.window_policy`，此处的组名是既有计算分类。

实际行运向查询两端扩展 400 天；次限向两端扩展 3 个回归年，并限制在出生后至次限引擎支持的 120 岁内。搜索未覆盖完整区间时显式返回未知边界，不保证任意长期配置都能找到起止。容许度只是所选规则下的几何范围，不是情绪、关系或现实事件的实际起止。

区间扫描使用行运 1 天、次限非月亮 7 个民用日、次限月亮 1 个民用日网格；加入速度变号求得的留驻点，再求两侧容许度边界。时间精度声明为分钟。精确事件仍由现有求根器计算；区间可以出现没有精确事件的留驻擦边接触。没有新增留驻事件或心理阶段标签。

次限月相由次限月亮减次限太阳计算，每 45 度一个阶段；不是次限月亮对本命月亮的周期。`phase_at_start` 是查询起点状态，`phase_transitions` 为空只表示窗口内没换相。次限日月换座事件仍在 `events` 内。

## 使用顺序

先读 `progressed_context` 与活动周期，再对照 `aspect_windows` 的持续配置和 `events` 的精确接触。需要解释时结合本命和当事人的现实；本工具不自动选出唯一主线，不以条目数量评分，也不推断确定事件。

本版为向后增加字段及扩大事件覆盖，事件数及原来的数组索引可能改变。重新取得结果后使用该次结果的索引和计算引用，不沿用旧结果的索引。图表、次限单独工具和其他行运工具的算法口径未随此改动扩大。
