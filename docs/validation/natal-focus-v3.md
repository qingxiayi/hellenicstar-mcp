# 本命焦点规则 v3 本地验证

日期：2026-10-22。状态：源码已修改、已本地验证；本轮没有推送、部署或重启线上服务。

## 修复范围

互容一直存在于结构事实和画像，但此前未登记到双方的候选依据。v3接通候选入口，同时把与同一入庙双节点闭环同义的互容标为 `synonymous_relation`，不增加另一结构族。无相位不删除关系；互容本身不直接触发单星入选，也不代表有效资源。

新增两个明确工程入口：命主星的直接外部定位星（只一层，遵循当前守护配置），以及现有Jones引擎提供的单一可识别焦点。后者保留原版本与置信信息；缺失或不能识别则明确标记，不猜测。所有十星画像、当前档内完整相位、定位终端和资源状态均保持。

报告逐项对照另补 `soft_aspect_with_essential_condition` 事实主题：当前档内的六合／三分与另一端的失势、落陷或游离标记显式关联，附双方来源，不生成好坏或有效用药判断。不改变重点入选。测试覆盖方向性、重复归并、未知状态不误判。

`natal-priorities-v3` / `natal-focus-v3` 独立版本化；输入参数、旧图谱接口不变。没有总分、指定赢家或人数上限。源码没有个人出生日期和固定入选行星。个人案例数据仅在本地临时目录复算，不纳入公共样本。

- 针对性测试覆盖：互容无相位仍登记双方；互容单独不自动入选；互容／闭环同义不多算；命主星自定位、缺ASC、传统／现代守护、仅一层承接；格局焦点缺失／未知／合法中英文名称；状态变化不改变重点；真实MCP调用、引用复算与篡改拒绝。
- 既有1,294组输入：1,245完整、36部分可计算；13组无效时间／歧义／越界输入按预期返回明确状态。
- 新种子 `2026102203` 生成300组未用于规则调整的输入，全部完整可计算。
- 768组起点范围、守护体系与相位档组合通过；抽样输入重排与重复不改变结果。
- 与修改前v2文件快照对照：1,581组可计算输入的共同终端及全部十星画像完全一致。新增规则只改变重点候选和审阅结构。完整断言及覆盖见 [审计JSON](natal-focus-v3-audit.json)。

## 已知限制与代价

本轮证明的是遗漏入口修复、明确规则可复算及事实保真。没有专业标注的“应入选名单”，不能从通过测试或入选数量变化推断专业准确率，也没有声称复原原报告的全部筛选公式。Jones焦点仍依赖上游引擎的规则质量。本轮未改尊贵、相位容许度、有效用药或心理解释。
