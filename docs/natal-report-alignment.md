## 逐项处理

| 对照项 | 当前处理 | 结论 |
|---|---|---|
| 定位终端、外部入口、不同统计起点 | 保留单星、双星、多星与多个终端，列完整路径 | 已计算；不强制唯一核心 |
| 互容参与筛选 | 双方候选均可追溯，无相位不删除；与同义闭环归并 | 已补齐漏接 |
| 命主星的承接关系 | 只选择直接外部定位星，按当前守护体系计算 | 已补齐；不是递归提升整条链 |
| 既有格局焦点 | 保留上游Jones引擎原结果、版本与置信信息 | 工程附加依据；报告未明确使用，不冒称还原 |
| 本体状态、宫位关联、刑冲 | 独立事实主题及完整状态画像 | 已计算，不是心理诊断 |
| 六合／三分与对方状态的组合 | 显式记录对方失势、落陷或游离标记与相位来源 | 已补齐；不推断相位有害或有效 |
| 报告中的交点接触 | 单独输出真南北交点接触，同轴表达去重 | 已补齐；不混入七星链或十星构型 |
| 三分尊贵 | 三分主身份、昼夜次序、当值规则是否计入分别输出；游离主题保留规则上下文 | 成员身份可与报告“三分性支持”一致；报告计值未说明，不能据未计入认定冲突 |
| 相位与构型范围 | 披露上游表与6/8/10度各档的实际集合 | 默认明确；报告未提供穷举列表及容许度表，不能反推 |
| 失势／落陷术语 | 分别记录对宫于入庙与对宫于擢升 | 不为匹配中文泛称而合并不同事实 |
| 轴点小数差异 | 保留实际坐标及数值，做坐标敏感性对照 | 坐标会改变结果；报告缺精确坐标，原因未能唯一确定 |
| “最好用”及必须先后处理的顺序 | 列关系、状态和依赖，不输出疗效或成长命令 | 报告无可复算公式，不能由单一案例反造规则 |

“核查完成”指可计算缺项已补、已知规则已披露、未知项已明确登记；不表示已经取得原报告引擎或证明其全部综合判断。

后续注意力分组验收另发现两项规则覆盖问题：对冲端点未进入单星构型角色入口，以及包含关系使已有相位依据从单星分组中消失。此前的事实覆盖结论不等于筛选层已经完成；当前暂不进入发布，见[规则验收](validation/natal-attention-acceptance.md)。

这两项已在本地 `natal-attention-v2` 修复；新层保留端点角色、被包含的原依据及其代表结构，同一网络只保留一个角色组。旧接口名单不改写，修复结果需要读取新层。详见[v2验证](validation/natal-attention-v2.md)，本轮仍未发布。

## 查证依据与边界

1. Valens《Anthologies》第二卷第一章区分三分主的昼夜优先及共同参与。核读了 [Riley译文的重排版本](https://raw.githubusercontent.com/janegca/latex-valens/main/Valens-Anthologies-Annotated.pdf) 中该章及Table 2.1（重排页89–90）。这支持区分主星身份与昼夜角色，但不能据此推断用户报告究竟如何给尊贵计值。当前程序复用自身Dorothean表，不将整套规则称为已经复制某个作者的完整算法。
2. [Swiss Ephemeris官方编程接口](https://www.astro.com/swisseph/swephprg.htm) 分别定义真交点与平均交点。本系统使用真交点，不能悄悄用另一种模型对齐报告数值。
3. 容许度的实际依据是当前代码 `NatalChartCalculator.ASPECT_ORBS`：主要相位上游10度，结构视图再截取6/8/10度。报告没有完整规则表；没有把网络文章中的偏好设成报告的规则，也没有通过删去额外构型来拟合案例。

- 三分语义补充后，当前工作区全套915项测试通过；此前隔离本命改动的878项及HTTP验证属于补充前记录，未冒称本次重跑。全套有一项既有Kerykeion `utcnow` 弃用警告。
