# 本命重点分组 v2：角色保留修复

2026-10-22。已本地实现和验证，未推送、未部署、未修改网页。

## 修正范围

仅升级 `attention_layers` 的分组策略为 `natal-attention-v2`：

- 构型对冲端点接入相位网络角色；两端使用同一规则，不指定唯一赢家。
- 保留被大构型包含的顶点／调节角色，并列出代表它的最大构型。
- 紧密相位无论独立还是被构型包含，都能补充已有角色；单独参与紧密相位仍不会自动升级为重点。
- 所有上述依据归入一个 `aspect_network` 组。`aspect_network_evidence` 追溯各项依据，`network_geometry_ids` 对底层相位去重；多个构型不能产生多个网络票数。
- 普通构型成员不因成员身份自动升级。旧 `priority_planets`、`focus_selection` 及完整状态字段保留原值；新客户端需读取新层，不能用旧名单裁剪它。

## 验证

- 全套930项测试通过，1项既有Kerykeion `utcnow` 弃用警告。
- 新增回归覆盖：紧密相位由独立变为被包含后不丢依据；五类角色在被包含后保留；相同网络只形成一组；对称端点平等保留、普通成员不升级。
- 重跑原验收300张合成盘、6／8／10度共900个视图：最大构型对冲端点未进入该星网络角色的情况由222张降为0；放宽6到8度后丢失原交叉重点的情况由44张降为0。新增断言同时检查6到8到10度的角色交叉保留、角色追溯和底层几何去重，无失败。
- 完整批量复测1,294组既有输入和相同种子2026102205的1,000组输入，1,104组配置切换，无断言失败。既有输入仍为1,245完整、36部分可算、13预期无效／歧义状态；同批1,000组均完整可算。
- 两份私有案例复算：除 `attention_layers` 外旧字段保持相同。私人数据及结果只存本地临时目录。

## 名单变宽的代价

修复恢复了原先被压掉的角色，不能宣传为“名单更短”。同批1,000张盘的平均交叉重点数量由3.442增至4.333；8颗及以上的宽清单由1张增至5张。此次无10颗全进入交叉组的样本，但规则没有人数上限，不能据此承诺不会发生。

原来的问题是信息进入筛选时被压掉，本轮解决的是这两项明确缺口，不是报告作者综合取舍的准确率验证。结构组、交叉重点和单入口重点仍须一起读取；交叉重点不是总排名。未公开的报告计值、容许度及资源有效性公式没有在本轮补造。
