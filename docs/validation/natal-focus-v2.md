# 本命焦点筛选 v2 验收

## 本次修正

v1将终端成员、任意主要轴点相位、紧密相位两端和全部构型成员都直接列为重点单星，导致宽入口几乎覆盖全盘。v2保留全部事实，改为分组对象与单星焦点分开：主要外部入口、身份、合轴、最大构型的不对称角色直接入选；其余单星需要至少三个不同结构族共同指向。被包含的小构型和相位边不再重复增加结构族。该门槛是公开的工程规则，不冒充报告原始公式，也不声称统计独立。

共同终端和对称构型仍以整组呈现；没有外部入口不强造入口，没有不对称角色不指定第一名。全部十星画像、相位及候选连接仍可读取，未入选理由逐项保留。不设人数上限；8颗以上只提示结果较宽，不截断。

## 发布验收门槛

- 解析反例：对称组不任意选单星；风筝及内部大三角／相位边不重复促进成员；轴点六合与合轴分开；两种宫制不作两票；主要入口并列保留。
- 保真：所有终端和构型保留，全部十星画像及当前档相位保留，关系核查不因重点筛选缺失端点。
- 稳定：重复或乱序输入不变；尊贵或逆行变化不单独改变焦点；缺轴点不生成轴点入口。
- 通用：已有合成集之外另生成300组输入；跨统计口径、守护体系和相位档验证；不设固定赢家或目标人数。
- 接口：真实MCP可调用、可复核，篡改新字段会被拦截；全量回归、两平台CI和生产候选验证通过后才切换。

## 版本与使用

输出 `natal-priorities-v2`；角色索引 `natal-priority-policy-v3`；阅读分组 `natal-reading-v2`。输入参数不变。`priority_planets` 为新的重点单星，`candidate_planets` 是旧宽入口记录，`planet_profiles` 为全部十星画像；`focus_selection` 包含整组结构与单星选择政策。旧客户端不能复用旧数组下标，应使用新结果的引用或按行星ID读取。

本轮仅优化本命结构提取。由个人本命盘的关系视角生成的关系测算，是另一个待单独设计和验证的算法，不包含在此次发布中。
