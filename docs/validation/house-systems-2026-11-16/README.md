## 实现范围

统一宫头与落宫计算、ARMC 推进、宫制注册表与错误类型；本命位置从旧双制古典分析中分离。新增 `equal`、`koch`、`regiomontanus`、`porphyry`、`campanus`，连同原有 `placidus` / `whole_sign` 共七种。

本命数据及图、宫主星、日返及图、月返及图、次限及双圈图、戴维森及图、迁居及图均已接入。MCP 参数枚举、缺参提示、路由建议和算法来源同步更新。方法限定工具保留适用范围，见 [宫制说明](../../house-systems.md)。

高纬度不静默换宫制；整宫制、等宫制可独立于普拉西度计算。无效或退化/逆序的宫头明确拒绝。四轴采用原始纬度的 Swiss 输出，不采用 Kerykeion 自用的限制纬度。

原代码对“天体恰好等于某宫头”的归属存在两套规则。本次统一为从该宫头开始的宫，即左闭右开区间；没有提前入宫容许度。普通旧案例快照保留，边界行为有专门测试。计算缓存版本由 v2 升为 v3，绘图缓存由 13 升为 14。

## 专业网站对拍

### Astrodienst / astro.com

入口：[Swiss Ephemeris Test Page](https://www.astro.com/swisseph/swetest.htm)。通过真实表单取得输出地址后，按同一公开接口读取不同参数的表格。网站报告 Swiss Ephemeris 2.10.04，本机为 2.10.03。

使用虚构测试时刻，不关联真实个人：

| 案例 | UTC 时刻 | 纬度 | 经度 |
|---|---|---:|---:|
| 巴黎 | 1990-04-15 16:00 | 48.8566 | 2.3522 |
| 悉尼 | 2000-01-01 12:00 | -33.8688 | 151.2093 |
| 纽约 DST 第一次 01:30 | 2024-11-03 05:30 | 40.7128 | -74.0060 |

每个时刻分别计算七宫制，共 21 张盘、252 个宫头。宫头和 ASC/MC 最大绝对角差均低于 0.001 角秒；实测宫头最大 0.000179375 角秒，与网站小数输出的舍入精度一致。

还用精确坐标生成 MCP `location_id`，将 UTC 转成当地时间后实际调用本命接口，检查时区/DST/宫制传递后的宫头与行星。十颗主行星输出保留四位小数，最大差 0.17676 角秒，处于该输出精度内。

这是跨服务与参数接入的验证；两端使用同一 Swiss Ephemeris 算法家族，不是独立天文学算法证明。

### Astrotheme

入口：[Birth Chart with Ascendant](https://www.astrotheme.com/birth-chart-sign-ascendant.php)。用公开匿名表单提交虚构测试资料，未注册或登录。浏览器广告遮挡并造成 CDP 超时后，关闭故障标签页，改用公开表单的正常 HTTP 请求获取结果。

该表单支持 Placidus / Equal Houses / Koch。本次分别在巴黎与悉尼测试，共六张盘。明确关闭 `Next House Shift`（设为 `No Shift`），避免网站默认的提前入宫规则影响比较。

网站给出的坐标和 UTC：

- 巴黎：东经 2°20′，北纬 48°52′；1990-04-15 当地 18:00 = 16:00 UTC。
- 悉尼：东经 151°13′，南纬 33°52′；2000-01-01 当地 23:00 = 12:00 UTC。

使用这些网站坐标重新计算，未混用 GeoNames 城市中心坐标。网站位置表只显示到角分。

结果：新增 Equal / Koch 四张盘的 48 个宫头及四轴、主行星位置均在半角分显示舍入范围内；六张盘的 60 个主行星落宫全部一致。

**保留的差异：** Astrotheme 的普拉西度表中，巴黎第 2/8 宫相差约 31.37 角秒，悉尼第 2/8 宫约 46.63 角秒、第 3/9 宫约 39.35 角秒，超过仅由角分四舍五入应产生的 30 角秒。没有放宽这个标准，也不把这两张普拉西度盘记为完全通过。已加载本次修改前保存的 `NatalChartCalculator.calculate_houses`，在相同输入下与新版逐宫比较，差异均为 **0**；因此不是此次升级引入的回归。网站内部实现/更精确坐标未核实，差异原因保持未解释。

- [逐案例结果，包括未解释差异状态](astrotheme-comparison.json)
